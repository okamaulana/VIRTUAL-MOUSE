# VIRTUAL-MOUSE

**Virtual Mouse** adalah aplikasi pengendali kursor komputer berbasis *hand tracking* yang memanfaatkan teknologi *Computer Vision* untuk menerjemahkan gerakan dan gestur tangan menjadi perintah input secara real-time melalui webcam.

Aplikasi ini memungkinkan pengguna menggerakkan kursor, melakukan klik kiri dan kanan, serta scrolling menggunakan gestur tangan tanpa memerlukan mouse fisik. Sistem dirancang untuk menghadirkan interaksi komputer yang lebih intuitif, interaktif, dan efisien.

## Fitur Utama

* **Real-Time Hand Tracking** — Mendeteksi dan melacak pergerakan tangan melalui webcam.
* **Cursor Control** — Menggerakkan kursor berdasarkan posisi ujung jari.
* **Left Click** — Melakukan klik kiri menggunakan gestur tangan.
* **Right Click** — Melakukan klik kanan menggunakan gestur tangan.
* **Scrolling** — Menggulir halaman dengan gerakan jari.
* **Touchless Interaction** — Mengoperasikan komputer tanpa menyentuh mouse fisik.

## Teknologi

Proyek ini menerapkan konsep *Computer Vision* dan *Hand Tracking* untuk mendeteksi posisi serta mengenali gestur tangan sebagai input kendali komputer.
