# VIRTUAL-MOUSE
Mouse Virtual berbasis Hand Tracking yang memungkinkan pengguna mengendalikan kursor komputer sepenuhnya menggunakan gerakan dan gestur tangan di depan webcam. Memanfaatkan teknologi Computer Vision, proyek ini mendeteksi ujung jari untuk menggerakkan kursor dan mengenali gestur tertentu (seperti mencubit atau menyatukan jari) untuk melakukan klik kiri, klik kanan, hingga scrolling tanpa menyentuh mouse fisik.
